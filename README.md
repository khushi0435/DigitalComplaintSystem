# Digital Complaint Management System

## Project Overview
The Digital Complaint Management System is a Python-based desktop application that helps users manage complaints digitally. It provides a simple graphical interface to add, view, edit, delete, and update complaint statuses.

## Features
- Add new complaints
- View all complaints
- Edit complaint details
- Delete complaints
- Update complaint status: Pending, In Progress, and Resolved
- Search and filter complaints
- Dashboard displaying complaint statistics
- Store complaint records using SQLite

## Technologies Used
- **Programming Language:** Python
- **GUI:** Tkinter
- **Database:** SQLite
- **IDE:** Visual Studio Code

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Run the following command in the terminal:

   `python main.py`

## Learning Outcomes
This project demonstrates Python programming, GUI development, database management, SQL queries, and CRUD operations.
